# Empty State

Create an empty state for a list with no items.

## Prompt

Build a React component with Tailwind CSS that shows an empty state when there are no dashboards. Include:

1. Centered content with:
   - An icon (use a simple SVG placeholder)
   - Title "No dashboards yet"
   - Description text explaining how to create one
   - Primary action button "Create dashboard"
   - Secondary action link "Import dashboard"

The empty state should:

- Not feel overwhelming or take up too much space
- Be appropriate for a professional tool
- Use dark theme styling
- Encourage the user to take action without being pushy
