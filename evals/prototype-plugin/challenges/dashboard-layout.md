# Dashboard Layout

Create a dashboard layout with multiple panels.

## Prompt

Build a React component with Tailwind CSS that shows a dashboard with monitoring panels. Include:

1. A dashboard header with:
   - Breadcrumb: "Dashboards > Infrastructure"
   - Dashboard title "Production Metrics"
   - Time range picker (just a dropdown placeholder)
   - Refresh button

2. A 2x2 grid of panels, each with:
   - Panel header with title and menu button
   - Placeholder content area

3. Panel titles:
   - "CPU Usage"
   - "Memory Usage"
   - "Network I/O"
   - "Disk Usage"

Use a dark theme. Panels should have minimal chrome and maximize content area. The overall layout should feel dense and professional.
