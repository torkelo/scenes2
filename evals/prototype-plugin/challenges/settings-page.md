# Settings Page

Create a settings page for configuring alert notification channels.

## Prompt

Build a React settings page component with Tailwind CSS that allows users to configure notification channels for alerts. Include:

1. A page header with:
   - Title "Notification Channels"
   - Description text
   - "Add channel" button

2. A form section with:
   - Name input field
   - Type dropdown (Email, Slack, PagerDuty, Webhook)
   - Configuration fields based on type (just use Email for this example: email address input)
   - Enable/disable toggle

3. Action buttons:
   - Cancel button (secondary)
   - Save button (primary)

Use a dark theme appropriate for a professional monitoring tool. Make it data-dense but readable.
