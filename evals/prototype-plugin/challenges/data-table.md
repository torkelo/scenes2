# Data Table

Create a data table showing alert rules.

## Prompt

Build a React component with Tailwind CSS that displays a table of alert rules. Include:

1. A header section with:
   - Title "Alert Rules"
   - Search input
   - "New rule" button

2. A table with columns:
   - Checkbox for selection
   - Name (with link styling)
   - Status (badge: Firing, Pending, Normal)
   - Last evaluation time
   - Actions (edit, delete icons)

3. Include 5-6 sample rows with realistic data

4. Table features:
   - Sortable column headers
   - Row hover state
   - Sticky header

Use a dark theme appropriate for a professional monitoring tool. Make it data-dense.
