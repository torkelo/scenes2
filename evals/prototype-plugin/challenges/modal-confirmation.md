# Confirmation Modal

Create a delete confirmation modal.

## Prompt

Build a React modal component with Tailwind CSS for confirming a destructive action. The modal confirms deleting a dashboard named "Production Metrics".

Include:

1. Modal overlay (semi-transparent dark background)
2. Modal content with:
   - Title "Delete dashboard"
   - Warning message explaining the consequences
   - Dashboard name being deleted
   - Cancel button (secondary)
   - Delete button (destructive/red)

The modal should:

- Be centered on screen
- Have appropriate border radius
- Use dark theme styling
- Feel serious but not alarming
- Have keyboard-accessible close (mention Escape key in implementation)
